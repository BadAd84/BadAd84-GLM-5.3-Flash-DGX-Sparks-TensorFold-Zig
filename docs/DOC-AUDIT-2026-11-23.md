# Documentation audit against the env decisions D1-D9 (2026-11-23)

value is the engine's own default and recorded debt, `prod.env` is the recipe we intend to ship, `dev.env` is prod plus
candidates, measurements run on `KNOBS=dev`, a promotion moves a line with its cells, a base that adds a table row is a
hard stop, the duplicate `SOLO_TO_START` row goes, and the six names with no table row are recorded as raw `getenv`
reads. This file lists every sentence found that contradicted that set, and what was done. It replaces nothing: the
model itself is `docs/ENV-REGISTER.md`.

## Flags for the owner (not resolved unilaterally)

1. **Blank values.** 16 rows have no expressible value: the engine's default is "no value" (no dump file, no captured
   kernel set, no HIP limit, no key file, no max) or the launcher computes it per boot (`TF_GLM_RANK`,
   `TF_GLM_WORLD`, `TENSORFOLD_MEMORY_RESERVE_GIB`). They are lines with an empty value, and `serve.sh` does not pass
   them. If the intent is that every line must carry a value the engine parses, those 16 need something else:
   `TENSORFOLD_CUDA_KERNELS=native` (forces the engine's own kernels instead of discovering a captured set beside the
   executable); `TF_DSPINE_WINDOW` and `TF_QWEN_KV_PAGE_TEST` are blank because their own rows have minimums 16 and 1,
   so the readers' 0 (off / the drafter's own window) has no legal text at all; the rest have no legal text either. The
   gate refuses a blank line on a row whose `blank_default` is false, so a blank here can only be a row that accepts the
   absent setting. The chosen reading is recorded here so it can be reversed in one decision.
2. **`TF_ROCE_GID_INDEX=3`** is the index the engine's own search picks on all four HCAs of spark1 today (probed). A host
   with a different GID table would need its own value; the value is pinned rather than searched, which is the price of
   setting the row.
3. **`TF_GLM_PROMPT_MANY`** is a candidate, not a promotion: its cells are the `port-multi-fill` ladder, measured on the
   `mf1` image carrying that package (its standalone predecessor cannot stack with it). Promotion is D6's move, with the
   cells, when the owner accepts them.
4. **A cross-lane note, not edited here.** `scripts/queues/queue118.sh` (another lane's fast screen, uncommitted when
   this pass ran) says in its rule that an UNCLEAR arm is "recorded `default-ok` with both rows". That word no longer
   exists: a neutral screen result is a `debt` verdict with its cells, or stays debt at the engine default. The queue's
   author (or Main) should change it before the queue lands; editing another lane's in-flight file was out of scope.
5. **Debt is 69 rows** (`scripts/env/register.env`): each is set to the engine's default and unmeasured on this stack.
   That list is the measurement worklist, not a defect list.
